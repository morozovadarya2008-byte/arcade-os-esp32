# Arcade OS for ESP32-C3 Super Mini

Простая операционная система / графическая оболочка для создания мини-аркадных игр и приложений на базе компактной платы **ESP32-C3 Super Mini**.

## 🚀 Возможности
- Поддержка дисплея OLED 0.96" по протоколу I2C.
- Управление с помощью двух физических кнопок (Левая / Правая).
- Минималистичный и легковесный код для микроконтроллеров ESP32.

## 🛠 Железо (Hardware)
* **Микроконтроллер:** ESP32-C3 Super Mini
* **Дисплей:** OLED 0.96" (драйвер SSD1306, разрешение 128x64)
* **Управление:** 2 тактовые кнопки

## 📌 Схема подключения (Распиновка)

### 📺 Дисплей OLED SSD1306

| Устройство | Пин дисплея | Пин платы ESP32-C3 |
| :--- | :---: | :---: |
| **OLED** | VCC | 3.3V |
| **OLED** | GND | GND |
| **OLED** | SDA | GPIO5 (D1) |
| **OLED** | SCL | GPIO6 (D2) |

### 🕹 Кнопки управления

| Устройство | Нога кнопки | Пин платы ESP32-C3 |
| :--- | :---: | :---: |
| **BUTTON_LEFT** | 1 | GPIO2 (D4) |
| **BUTTON_LEFT** | 2 | GND |
| **BUTTON_RIGHT** | 1 | GPIO3 (D3) |
| **BUTTON_RIGHT** | 2 | GND |

## 💻 Как запустить проект
1. Установите [Arduino IDE](https://arduino.cc) (или PlatformIO).
2. В менеджере плат добавьте поддержку **ESP32** от Espressif.
3. Установите библиотеки для работы с экраном (например, **Adafruit SSD1306** и **Adafruit GFX Library**).
4. Выберите плату `ESP32C3 Dev Module`.
5. Скомпилируйте и прошейте ваш скетч в плату.
